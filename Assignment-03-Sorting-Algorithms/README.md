# Assignment 3 – Sorting Algorithms

**Subject:** Data Structures I  
**Language:** C++  
**Institution:** Deccan Education Society, Pune University

## Project Overview

A menu-driven C++ program that implements four sorting algorithms using arrays. The application accepts elements from the user, sorts them using the selected algorithm, and compares their performance based on the number of comparisons and swaps or shifts.

## Algorithms Implemented

1. **Bubble Sort** – Repeatedly compares adjacent elements and swaps them when they are in the wrong order.
2. **Selection Sort** – Finds the smallest element from the unsorted portion and places it in its correct position.
3. **Insertion Sort** – Builds a sorted array by inserting each element into its correct position.
4. **Quick Sort** – Uses the divide-and-conquer approach by selecting a pivot and partitioning the array.

## Features

- Menu-driven interface.
- User-defined array input.
- Individual execution of all four sorting algorithms.
- Displays sorted arrays.
- Counts comparisons and swaps/shifts.
- Compares the performance of all algorithms.
- Validates the number of input elements.

## Time Complexity

| Algorithm | Best Case | Average Case | Worst Case |
|---|---|---|---|
| Bubble Sort | O(n) | O(n²) | O(n²) |
| Selection Sort | O(n²) | O(n²) | O(n²) |
| Insertion Sort | O(n) | O(n²) | O(n²) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) |

## How to Run

1. Open the project in a C++ IDE or compiler.
2. Compile `main.cpp`.
3. Run the program.
4. Enter the number of elements and the array values.
5. Select a sorting algorithm from the menu.
6. Select option 5 to compare all algorithms.

# Assignment 8 – Student Record Management System

**Subject:** Data Structures I  
**Language:** C++  
**Assignment:** 08  
**Institution:** Deccan Education Society, Pune University

## Project Overview

A menu-driven Student Record Management System developed using C++ File Handling.

The program allows users to create a student records file, add student details, display saved records, and delete student records using their PRN numbers.

Student information is stored permanently in a text file.

## Features

- Create a student records file.
- Add student names and PRN numbers.
- Display all stored student records.
- Delete student records using PRN.
- Use temporary files to update records.
- Menu-driven interface.

## Technologies Used

- C++
- File Handling
- Standard Input/Output
- Text File Operations

- `fstream`

## How to Run

1. Open the project in Dev-C++ or another C++ IDE.
2. Compile `main.cpp`.
3. Run the program.
4. Select the required operation from the menu.
5. Student records are stored in `students.txt`.

## Menu Options

1. Create File
2. Add Student Record
3. Display Records
4. Delete Student Record
5. Exit

## Learning Outcome

This assignment demonstrates the practical implementation of file handling in C++. It provides experience in storing, retrieving, appending, and deleting records using text files.

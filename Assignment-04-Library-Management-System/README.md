## Project Overview

A C++ based Library Management System developed using an array of objects and searching algorithms.

The application manages book records and allows users to search for books using different fields, identify the highest and lowest priced books, and count books written by a particular author.

## Features

- Store book details including ISBN, Book Name, Author Name, Publisher Name and Price.
- Search books using ISBN through Binary Search.
- Search books using Book Name, Author Name and Publisher Name through Linear Search.
- Display the highest-priced and lowest-priced books.
- Count the number of books written by a particular author.
- Display all available book records.
- Menu-driven user interface.

## Technologies Used

- **Programming Language:** C++
- **IDE:** Visual Studio / C++ IDE
- **Concepts:** Arrays, Classes, Objects and Searching Algorithms.

## Data Structures and Algorithms

- Array of Objects
- Linear Search
- Binary Search
- Bubble Sort
- Minimum and Maximum Element Identification
- Searching and Filtering

## Learning Outcomes

- Understanding arrays of objects in C++.
- Implementing Linear and Binary Search.
- Understanding sorting before applying Binary Search.
- Working with classes, objects and encapsulation.
- Applying searching algorithms to real-world applications.
- Understanding basic algorithm complexity.

**Deccan Education Society, Pune University**

## Project Overview

A menu-driven Cricket Player Management System developed using C++. The application uses a Singly Linked List to store and manage cricket player records dynamically.

Each player record contains:
- Player ID
- Player Name
- Mobile Number
- Age

## Features

1. Add a new player.
2. Delete a player using Player ID.
3. Display all player records.
4. Search for a player by name.
5. Update a player's mobile number.
6. Exit the application.

## Data Structure Used

**Singly Linked List**

Each node contains player information and a pointer to the next node. The last node points to NULL.

## Concepts Implemented

- Structures and pointers
- Singly Linked Lists
- Dynamic memory allocation
- Node creation and traversal
- Insertion and deletion
- Searching and updating
- Memory management
- Menu-driven programming

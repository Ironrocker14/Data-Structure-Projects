**Deccan Education Society, Pune University**

## Project Overview

A menu-driven C++ program that performs various matrix operations using two-dimensional arrays.

The program allows users to perform addition, subtraction, multiplication, transpose, and upper triangular matrix operations.

## Operations Implemented

- Matrix Addition
- Matrix Subtraction
- Matrix Multiplication
- Matrix Transpose
- Upper Triangular Matrix Display
- Dimension Validation

## Concepts Used

- Two-Dimensional Arrays
- Functions
- Loops
- Conditional Statements
- Switch Case
- Matrix Operations

## Technologies Used

- Language: C++
- IDE: Eclipse
- Concepts: Data Structures and Programming Fundamentals

## How to Run

1. Download or clone this repository.
2. Open the project in a C++ IDE.
3. Compile `main.cpp`.
4. Run the program.
5. Select an operation from the menu.

## Time Complexity

| Operation | Time Complexity |
|---|---|
| Addition | O(r × c) |
| Subtraction | O(r × c) |
| Multiplication | O(r1 × c1 × c2) |
| Transpose | O(r × c) |
| Upper Triangular | O(n²) |
